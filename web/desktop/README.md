# PMail Desktop Web

`web/desktop` 是 PMail 的桌面 Web 前端（Vue 3 + TypeScript + Vite + Arco Design Vue）。后续移动端前端放在 `web/mobile`。

```sh
bun install --frozen-lockfile
```

### Compile and Hot-Reload for Development

```sh
bun run dev
```

### Type Check

```sh
bun run typecheck
```

### Compile and Minify for Production

```sh
bun run build
```

### Lint with ESLint

```sh
bun run lint
```
