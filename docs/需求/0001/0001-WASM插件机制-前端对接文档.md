# 0001 WASM插件机制 — 前端对接文档

> 状态：接口已实现，前端页签已接入并构建通过；未做浏览器联调
> 分支：master ｜ 日期：2026-11-11

本文是 WASM 插件管理接口的对外契约。入口位于设置弹窗的「插件设置 / 插件管理」区域，仅管理员可见。

## 1. 接口与权限

| 项 | 说明 |
| --- | --- |
| 鉴权 | 必须已登录且为管理员；非管理员返回 `errorNo=405` |
| 请求方式 | `list` 仅接受 `GET`，其余 6 条仅接受 `POST`；`upload` 使用 `multipart/form-data` |
| 请求体 | JSON 上限 1 MiB；`upload` 的 zip 包上限 32 MiB |
| 响应外壳 | `{"errorNo":number,"errorMsg":string,"data":any}`，HTTP 状态码始终 200 |
| 基础路径 | `/api/plugin/manage` |
| 能力开关 | `list` 返回 `enabled=false` 时表示后端未启用 WASM 插件能力，页面应只展示提示，不发起写操作 |

错误码：

| errorNo | 含义 |
| --- | --- |
| `0` | 成功 |
| `100` | 参数错误、插件不存在、状态不允许、授权项不在 manifest、method 不符 |
| `405` | 非管理员 |
| `500` | 加载、编译或重载失败 |

## 2. 字段说明

插件对象：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 插件唯一标识，等于插件目录名 |
| `name` | string | 显示名 |
| `type` | string | 固定 `wasm` |
| `version` | string | 插件版本 |
| `abi` | string | 固定 `pmail-hook@1` |
| `status` | string | `pending` / `approved` / `enabled` / `disabled` / `rejected` / `error` |
| `hooks` | string[] | manifest 声明的钩子 |
| `capabilities` | string[] | manifest 声明的能力 |
| `grantedHooks` | string[] | 已授权钩子 |
| `grantedCapabilities` | string[] | 已授权能力 |
| `lastError` | string | 最近一次错误，无错误为空串 |
| `callCount` | number | 累计调用次数 |
| `errorCount` | number | 累计错误次数 |
| `lastUsedAt` | string | 最近调用时间，RFC 3339；未调用为空串 |

枚举：

| 字段 | 取值 | 含义 |
| --- | --- | --- |
| `status` | `pending` | 已发现，待审批 |
| `status` | `approved` | 已授权，未启用 |
| `status` | `enabled` | 已启用，实例运行中 |
| `status` | `disabled` | 已停用，授权保留 |
| `status` | `rejected` | 已拒绝，授权清空 |
| `status` | `error` | 加载或运行失败 |
| `hooks` | `SendBefore`、`SendAfter`、`ReceiveParseBefore`、`ReceiveParseAfter`、`ReceiveSaveAfter`、`GetName`、`SettingsHtml` | 7 个钩子 |
| `capabilities` | `log`、`email.read`、`email.write`、`http` | 能力，`http` 需配合 `http_allow` |

## 3. 接口明细与示例

### 3.1 插件列表

**请求参数**

无。

**请求示例**

```http
GET /api/plugin/manage/list
```

**响应字段**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `enabled` | boolean | 后端是否启用 WASM 插件能力 |
| `plugins` | object[] | 插件对象数组，按 `id` 升序 |

**响应示例**

```json
{
  "errorNo": 0,
  "errorMsg": "",
  "data": {
    "enabled": true,
    "plugins": [
      {
        "id": "example.spam-filter",
        "name": "示例反垃圾",
        "type": "wasm",
        "version": "1.0.0",
        "abi": "pmail-hook@1",
        "status": "pending",
        "hooks": ["ReceiveParseAfter"],
        "capabilities": ["log", "email.read"],
        "grantedHooks": [],
        "grantedCapabilities": [],
        "lastError": "",
        "callCount": 0,
        "errorCount": 0,
        "lastUsedAt": ""
      }
    ]
  }
}
```

### 3.7 上传插件

**请求参数**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `file` | file | 是 | `multipart/form-data` 文件字段；zip 根目录必须包含 `manifest.json` 与 manifest 声明的入口 wasm，最大 32 MiB |

**请求示例**

```bash

  http://127.0.0.1/api/plugin/manage/upload
```

**响应字段**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 新插件 `id` |
| `name` | string | manifest 显示名 |
| `status` | string | 固定 `pending` |
| `hooks` | string[] | manifest 声明的钩子 |
| `capabilities` | string[] | manifest 声明的能力 |

**响应示例**

```json
{
  "errorNo": 0,
  "errorMsg": "",
  "data": {
    "id": "example.spam-filter",
    "name": "示例反垃圾",
    "type": "wasm",
    "version": "1.0.0",
    "abi": "pmail-hook@1",
    "status": "pending",
    "hooks": ["ReceiveParseAfter"],
    "capabilities": ["log", "email.read"],
    "grantedHooks": [],
    "grantedCapabilities": [],
    "lastError": "",
    "callCount": 0,
    "errorCount": 0,
    "lastUsedAt": ""
  }
}
```

上传成功后插件以 `pending` 状态进入列表，需要继续执行「审批」；重复 `id`、包结构不合法、路径穿越或超过限制时返回 `errorNo=100`。

## 4. 错误文案

| 场景 | errorNo | errorMsg 示例 |
| --- | --- | --- |
| 非管理员 | 405 | `no access privileges` |
| method 不符 | 100 | `method GET not allowed` |
| 缺少 pluginId | 100 | `pluginId is required` |
| 插件不存在 | 100 | `plugin not found` |
| 状态不允许 | 100 | `plugin state does not allow this operation` |
| 授权项不在 manifest | 100 | `requested grant is not declared in manifest: hook Unknown` |
| 名称冲突 | 100 | `plugin name conflicts with an existing hook` |
| 能力未启用 | 100 | `wasm plugin feature is disabled` |
| 加载/编译失败 | 500 | 具体错误摘要，不含文件内容 |

前端展示建议：`errorMsg` 非空时直接展示；空时使用通用文案「操作失败」。

## 5. 注意事项

1. **方法约束**：列表用 `GET`，其余用 `POST`。后端路由不区分 method，但 handler 内部会拒绝错误方法并返回 `errorNo=100`。
2. **默认不授权**：审批弹窗默认不勾选任何钩子与能力；必须手动选择。
3. **授权范围**：`hooks` 与 `capabilities` 只能从 manifest 声明的项中选择，超范围返回 `100`。
4. **状态流转**：`pending → approved → enabled → disabled → enabled`；`reject` 可从任意状态执行；`reload` 仅用于已启用或错误状态。
5. **manifest 变化**：后端发现插件版本或文件哈希变化时，会把状态重置为 `pending`，旧授权失效，需要重新审批。
6. **失败回退**：`reload` 失败保留旧实例；页面应展示 `errorMsg` 并刷新列表。
7. **功能开关**：`list.data.enabled=false` 时不展示审批表格，只显示后端未启用提示。
