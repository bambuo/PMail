## 3. 需求边界

- 不新增业务功能，不调整页面信息架构与路由路径。
- 不改变现有接口路径、请求字段、响应包裹 `errorNo` / `errorMsg` / `data`。
- Cookie 鉴权与 `Lang` 请求头保持不变；路由从 Hash 模式切换为 History 模式，服务端为非 API 路径回退 `index.html`。
- 不在本轮引入后端 OpenAPI 代码生成、前端 E2E 框架或组件库二次封装层。
